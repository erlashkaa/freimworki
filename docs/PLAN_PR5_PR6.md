# План ПР5 и ПР6

Оба предоставленных задания по дисциплине «Технологии разработки приложений
на базе фреймворков» содержат одинаковые требования. Они выполняются одной
веб-версией FinanceTracker. Старые CLI и Tkinter продолжают работать с JSON;
веб-версия использует SQLite с привязкой записей к пользователю.

- [x] Django, модели, миграции и бизнес-правила.
- [x] REST API и документация контракта.
- [x] HTML/CSS/JavaScript интерфейс с fetch.
- [x] Сессии, права доступа, CSRF, валидация и ограничение входа.
- [x] Кэш сводки, индексы, пагинация и оптимизация запросов.
- [x] Модульные, интеграционные и нагрузочные проверки.
- [x] Развёртывание через Waitress и инструкции запуска.
- [x] Повторная проверка требований, старых функций и новых сценариев.

Внешний публичный сервер в задании не указан. Развёртывание проверяется
локально через WSGI-сервер; настройки для HTTPS описываются отдельно.

Результаты и соответствие каждому пункту: [PR5_PR6.md](PR5_PR6.md).
